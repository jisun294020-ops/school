# 컴퓨터를 켜면 뜨는 창업 브리핑 (Windows)

매일 **그날 처음 컴퓨터를 켤 때** 부천·경기 지역 IT 예비창업 지원 공고를 찾아서 보여줍니다.

## 동작 방식
1. Windows에 로그인하면 `briefing.ps1`이 자동으로 실행됩니다.
2. **Claude Code가 설치되어 있으면** 그 자리에서 웹을 검색해 브리핑을 만듭니다. 결과는 `문서\StartupBriefing\날짜.md`에 저장되고 메모장으로 열립니다. 1~3분 정도 걸립니다.
3. 같은 날 컴퓨터를 다시 켜면 새로 검색하지 않고, 이미 만든 브리핑을 다시 열어 줍니다.
4. **Claude Code가 없으면** 브라우저에서 `claude.ai/code`를 엽니다. 매일 아침 7:47에 클라우드에서 만들어진 브리핑 세션을 거기서 볼 수 있습니다.

## 설치 (한 번만)
1. 이 `startup-briefing` 폴더를 PC에 내려받아 원하는 곳(예: `C:\창업브리핑`)에 둡니다. **설치한 뒤에는 폴더를 옮기지 마세요.**
2. (권장) Claude Code를 설치하고 한 번 로그인합니다.
   - PowerShell에서 `irm https://claude.ai/install.ps1 | iex` 실행
   - `claude`를 실행해 로그인
3. `install.bat`을 더블클릭합니다.

## 테스트
`briefing.ps1`을 마우스 오른쪽 버튼으로 클릭한 뒤 **PowerShell에서 실행**을 고르면 바로 확인할 수 있습니다.

## 끄기
`uninstall.bat`을 더블클릭합니다.

## 검색 내용 바꾸기
`prompt.txt`를 메모장으로 열어 고치면 됩니다. 저장할 때 인코딩은 UTF-8로 두세요.
